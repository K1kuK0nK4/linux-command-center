SSH fingerprints (first contact)

With "confirm", the first time you connect to a server its fingerprint is left pending and no credential is sent until you accept it (on the server page or in Pending fingerprints). If the fingerprint changes later, the connection is always blocked.
For example your %USERPROFILE%\.ssh\known_hosts or a bastion's. servers listed in it will use that fingerprint directly, without confirmation.

Safe mode

Before running anything that could reboot, shut down or break a server, the application stops it and you must type CONFIRM. It is recorded in the Audit log. It works in Remote execution and in the terminal (it checks the line when you press Enter). In the file panel it prevents deleting and overwriting.
