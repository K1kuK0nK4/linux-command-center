How to find which servers are affected by a CVE

Search for the package with the condition < and the fixed version published by each distribution's vendor (Red Hat: access.redhat.com/security/cve/CVE-…, Ubuntu: ubuntu.com/security/CVE-…, Debian: security-tracker.debian.org).

RHEL and Ubuntu patch without bumping the main version (backporting): always compare with the vendor's version (e.g. 3.0.7-27.el9), not with the CVE's "upstream" version. Since each distro has its own fixed version, filter by family and run one search for each.

The running kernel appears as the package kernel-running.

Packages inside containers are marked with the container name and its image; they are compared using the image's distribution (not the host's). detection = version obtained by running the program (e.g. nginx -v), for software installed outside packages.
