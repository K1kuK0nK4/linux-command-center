Import

  1. Download the template: Excel · CSV. A file exported from here also works.
  2. Fill in one row per server. The Instructions sheet explains each column.
  3. Upload it:
When updating, empty cells do not erase anything and tags are added to the existing ones.

If the file contains passwords, delete it from your PC when you finish (and empty the recycle bin). Inside the application they are encrypted.

Export

Creates a file in the same format as the import: use it as a copy, to share with a colleague or to edit many servers in Excel and import it back.

The file will contain the passwords unencrypted. Keep it somewhere safe and delete it when you finish. This is recorded in the Audit log.
